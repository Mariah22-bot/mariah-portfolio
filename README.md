> **An interactive portfolio where the illustration becomes the primary navigation, complemented by a floating menu for quick access across the site.**

This project explores the concept of **Navigation as UI**, replacing traditional menus with an interactive illustration. Each visual element acts as a navigation point, creating an experience that blends creativity, UX/UI design and modern Front-end development.
