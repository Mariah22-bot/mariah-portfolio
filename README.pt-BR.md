> **Um portfólio interativo onde a ilustração se torna a navegação principal, complementado por um menu flutuante para acesso rápido às seções.**

Este projeto explora o conceito de **Navegação como UI**, substituindo menus tradicionais por uma ilustração interativa. Cada elemento visual atua como um ponto de navegação, criando uma experiência que mistura criatividade, design UX/UI e desenvolvimento Front-end moderno.

```bash

npm run dev
```

## `> comandos.disponiveis`

